# Employee Management Java

Java console application focused on object-oriented programming, collections, employee data processing, and business-rule exercises.

## Overview

This project demonstrates core Java concepts through an employee management scenario. It works with employee records, salaries, roles, dates, grouping, sorting, and formatted output.

## Features

- Employee registration using Java objects
- Employee removal by name
- Salary increase calculation
- Grouping employees by role
- Birthday filtering by month
- Oldest employee identification
- Alphabetical sorting
- Total payroll calculation
- Salary comparison using minimum-wage multiples
- Date and currency formatting

## Concepts Practiced

- Object-oriented programming
- Inheritance
- Java Collections
- `List` and `Map`
- `BigDecimal`
- `LocalDate` and `Period`
- Comparators and sorting
- Data formatting
- Basic business rules

## Tech Stack

- Java

## Running the Project

Compile the source files:

```bash
javac Pessoa.java Funcionario.java Principal.java
```

Run the application:

```bash
java Principal
```
